# Net Shooter

3D шутер от первого лица с сетевой игрой для двоих.

## Стек
- Клиент: React + TypeScript + Three.js + Vite
- Сервер: Node.js + `ws` (вебсокеты, комнаты, рассылка состояний 20 Гц)

## Структура
- `src/` — клиент (игру, сеть, бой, UI)
- `server/index.ts` — вебсокет-сервер с комнатами

## Запуск в разработке

```bash
npm install
# сервер (в одном терминале)
npm run server
# клиент (в другом терминале)
npm run dev
# или параллельно: npm run dev & npm run server
```

Клиент по умолчанию подключается к `ws://localhost:8787` (переменная `VITE_WS_URL`).

## Игровой процесс
- WASD + мышь — движение и обзор (перехват указателя)
- Shift — бег, ЛКМ — стрельба (hitscan)
- Режим «Сеть»: создайте комнату или введите код, друг подключается по тому же коду
- Здоровье отображается на HUD, при смерти — респаун

## Сборка
```bash
npm run build   # vite build (требует Node.js с нативными модулями)
npm run preview
```
